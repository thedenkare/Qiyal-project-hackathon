## 2. Объём

**P0 (сделано):** основной путь «загрузка → проверка → подтверждение → что изменилось → поставщики → экспорт цен», доменное ядро с тестами, проверки сумм, сопоставление с алиасами, честная маркировка ДЕМО, состояния ошибок, ручной ввод.

**P1 (сделано):** панель «Режим и НДС», разбор PDF с текстовым слоем, импорт продаж и каталога из CSV.

**P2 (не сделано):** казахский интерфейс, Telegram-бот, XML ЭСФ, провайдер Gemini.

## 3. Архитектура

Python 3.11, FastAPI, SQLModel/SQLite, Jinja2 + htmx (локально), Chart.js (локально), rapidfuzz, pydantic, Pillow, pdfplumber, pytest. Пакет `anthropic` нужен только для VisionLLM. OpenCV не используется: выравнивание наклона сделано на Pillow, чтобы установка на Windows была проще.

```
app/domain/pricing.py   себестоимость, маржа, цена, округление, потолок наценки
app/domain/changes.py   рост цен, медиана 3 закупок, статус, потери
app/domain/vat.py       сценарий утечки зачёта, пороги режима
app/extraction/         schema → engines → checks → matching → pipeline
app/services.py         склейка с БД: подтверждение, алерты, экраны
app/web/                маршруты и шаблоны
```

## 4. Решения, которые мы приняли сами

- **Порядок движков:** демо-эталон (только по SHA-256 демо-файла) → PDF-текст → Claude Vision → локальный OCR → ручной ввод. При каждом переходе на запасной движок показывается баннер.
- **Модель:** `claude-opus-5-5` через structured outputs (`messages.parse` + pydantic-схема), effort `low`, параметр `temperature` не передаётся (на этой модели его нет). Ответ строго по схеме; модель только переписывает числа, ничего не считает.
- **Себестоимость хранится как `unit_net` + ставка**, а эффективная себестоимость пересчитывается при каждом показе по текущему профилю. Поэтому смена ОУР↔СНР или флага ЭСФ сразу пересчитывает всё.
- **Ссылка для роста цен:** последняя закупка у того же поставщика, медиана трёх последних тоже хранится. Пороги: внимание ≥3 %, критично ≥8 % или маржа ниже пола (`config/app_settings.json`).
- **«Поднять цену»** предлагается, когда маржа ниже целевой больше чем на 1 п.п. Диапазон цены: от цены под пол маржи до цены под целевую маржу.
- **Утечка зачёта** считается только для профиля ОУР и только как сценарий.
- **При первом запуске** автоматически загружается демо, чтобы на экране не было пусто. «Начать со своими данными» очищает БД.
