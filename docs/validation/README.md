# Валидация без знакомых

Материалы:

- **(а) Пример результата на одну страницу**: запустите приложение → Настройки → «Пример результата (A4)», или откройте http://localhost:8000/example → «Печать». Он строится из текущих демо-данных, поэтому сначала пройдите сценарий из README (подтвердите накладную «Оптбаза»).
- **(б) Скрипт разговора на 5 минут**: [interview_script.md](interview_script.md).
- **(в) Шаблон ответов**: [answers_template.csv](answers_template.csv), открывается в Excel и Google Sheets, разделитель `;`.

План: 2–3 знакомства через организаторов Zhambyl Hub, около 30 магазинов Тараза из 2ГИС (стройка, хозтовары, автозапчасти), визиты в 5–8 из них, чтение mybuh.kz, Threads и Telegram-чатов предпринимателей.

Критерий: подтверждение, если у ≥3 из 5 цены пересматриваются редко и «на глаз» и они просят пример. Опровержение, если всё уже автоматизировано или накладные не важны.
